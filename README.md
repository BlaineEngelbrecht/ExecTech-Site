# ExecTech — static six-page website

Open `index.html` in a browser for a local preview, or upload all files and the `assets` folder to a GitHub repository and enable GitHub Pages (Settings → Pages → Deploy from branch → main / root).

Pages: Home, About, Behind the Scenes, Services, Clients, Get Started.

## Before going live
1. Replace `YOUR_FORM_ID` in `get-started.html` with your own Formspree form ID. Until then the form displays a preview warning instead of sending.
2. Review your privacy notice and add contact details, business registration information and any applicable legal pages.
3. Review claims, pricing and scope, and test on mobile.
4. Connect your purchased domain via GitHub Pages settings and your domain DNS when ready.

The founder portrait and brand reference image are in `assets`. The site uses a custom ET favicon and CSS brand styling. Google Fonts requires internet; fallback fonts work offline. No framework or build step is required.
